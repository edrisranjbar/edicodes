# قلم‌های محلی

- وزیر با رقم فارسی، وزن معمولی و ضخیم: برای متن، کنترل‌ها و نمودارها؛ از نسخهٔ موجود روی همین رایانه کپی شده است.
- مربع، وزن ضخیم: برای عنوان‌ها؛ از قلم نصب‌شدهٔ کاربر روی همین رایانه کپی شده است.

فایل‌های قلم داخل همین پروژه نگهداری می‌شوند. هنگام ساخت، دادهٔ هر سه قلم در سبک هر فایل HTML جاسازی می‌شود؛ در نتیجه حتی با انتقال یک فایل HTML به‌تنهایی، نمایش قلم به اینترنت یا نصب قلم وابسته نیست.

مسیر منبع محلی وزیر: `Desktop/projects/book-reader-app/fonts`.
مسیر منبع محلی مربع: `AppData/Local/Microsoft/Windows/Fonts`.
کپی محلی قلم‌ها مجوز تازه‌ای برای انتشار عمومی آن‌ها ایجاد نمی‌کند؛ مجوز اصلی هر قلم معتبر است.
